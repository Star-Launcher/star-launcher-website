# Star-Launcher Security Policy

## Supported releases

Security fixes are provided for the latest stable Star-Launcher release. Users
should update to the newest stable version before reporting a problem that may
already have been corrected.

## Reporting a vulnerability

Email `star.launcher.support@gmail.com` with the subject
`SECURITY: Star-Launcher vulnerability report`.

Please include:

- the Star-Launcher version;
- the affected feature and the result you expected;
- clear reproduction steps;
- the practical security impact;
- relevant logs or screenshots after removing personal information; and
- whether you believe public disclosure should be delayed while a fix is prepared.

Do not include passwords, authentication codes, API keys, private account data,
donor information, or unrelated files from your computer. Do not publicly disclose
an unpatched vulnerability before there has been a reasonable opportunity to
investigate and correct it.

The project aims to acknowledge a report within three business days and provide a
status update at least every seven days while it is actively investigated. These
are response targets, not a guarantee of resolution within a particular period.

## Scope

Reports about the Star-Launcher application, official update process, release
artifacts, and `star-launcher.com` are in scope. Vulnerabilities in games, launchers,
controller tools, websites, or other third-party products should be reported to
their respective maintainers unless Star-Launcher's handling of them creates the
security problem.

## Disclosure and credit

Please allow time for a supported release and user notice before publishing technical
details. The project will coordinate a reasonable disclosure date and can credit the
reporter unless anonymity is requested.

Public security information and download-verification instructions are available at
<https://star-launcher.com/pages/security>.
