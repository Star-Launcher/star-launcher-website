General

What is Star-Launcher?

Star-Launcher is a lightweight Windows launcher and startup utility designed to simplify the sim setup workflow.

Is Star-Launcher an official Star Citizen or RSI product?

No. Star-Launcher is an independent community project. It is not affiliated with, endorsed by, or sponsored by Cloud Imperium Games or Roberts Space Industries.

Does Star-Launcher replace official game launchers?

No. Star-Launcher is intended to organize your surrounding startup workflow, not replace official game launchers or bypass their requirements.

Installation and updates

Can I download Star-Launcher from this website?

Yes. Use the Download page to get the latest stable Portable ZIP and view its release notes.

Does Star-Launcher require an installer?

No. Download the Portable ZIP, extract it, and run Star-Launcher.exe. Star-Launcher does not install a background service or force a particular folder.

What kind of computer do I need?

Star-Launcher is designed for 64-bit Windows 10 and Windows 11 computers.

How do updates work?

Star-Launcher can check the official website for a newer stable release and apply supported updates while preserving its current location and user data. A manual Portable ZIP remains available from the Download page.

Games and tools

Can Star-Launcher start my head-tracking software?

Yes. Configure it as a universal Utility App, then choose which games include it in their launch routine. This helps avoid reaching the game and realizing the head-tracking app was forgotten.

Are controller tools required?

No. Controller preparation is optional. Enable only the tools used by your setup.

What is a controller preset?

A controller preset groups controller tools and preparation settings. Each game can select a preset, while exported presets omit machine-specific paths and never overwrite an existing preset during import.

Does Star-Launcher include vJoy, HidHide, Joystick Gremlin, or other third-party tools?

No. Optional third-party tools are never bundled. You install and configure them separately, then point Star-Launcher to them.

Can I add another game?

Yes. Native game tiles are included for supported titles, and the Add game tile creates a configurable game with a generic controller icon. Use Reorder on Main to arrange the tiles.

Startup and control

Can a game launch automatically when Star-Launcher opens?

No. Automatic profile launch at application startup was removed in 5.0. Starting Star-Launcher with Windows remains an optional universal Preference.

Can I stop a launch that is already running?

Yes. The progress window provides a Stop control and keeps the results visible so you can see what completed and what needs attention.

Does Star-Launcher automate game login or store my credentials?

No. It does not replace or bypass launcher login, two-factor authentication, CAPTCHA, updates, UAC prompts, or other official security requirements.

Data and access

Will an account be required?

No. The website has no account system, and Star-Launcher does not require a Star-Launcher website account.

Where are my settings stored?

User data is stored under %APPDATA%\Star-Launcher. Existing data from the older %APPDATA%\StarLauncher location is migrated automatically when applicable.

Is the source code public?

Not currently. Source publication remains under consideration. In the meantime, the project publishes security and privacy documentation, release checksums, deterministic test evidence, a dependency inventory, and download-verification guidance.
