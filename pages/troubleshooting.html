Troubleshooting

Start with safe, reversible checks and collect useful details before asking for community support.

Start here

Read the message shown in Star-Launcher’s progress window. It usually identifies the item that stopped or needs attention.

Use the official release.

If you need to download Star-Launcher again, use star-launcher.com. Do not replace files with copies from unofficial sources or turn off Windows security.

Star-Launcher will not open

  1. Make sure the ZIP was fully extracted before opening Star-Launcher.
  2. Open the extracted folder and double-click Star-Launcher.exe.
  3. If it still does not open, restart Windows and try once more.
  4. If Windows shows a security message, confirm that your download came from star-launcher.com.

Star-Launcher is designed for 64-bit Windows 10 and Windows 11.

An application says “No Path Set” or the wrong app opens

  1. Open Settings, then the Setup tab.
  2. Run auto-detection if useful, but verify every detected location.
  3. Browse to the correct executable manually when detection is missing or incorrect.
  4. Save the profile and run Pre-flight checks again.

Head tracking or another supporting app did not start

  1. Confirm the app is checked in the active profile on the main page.
  2. Confirm its executable path is correct.
  3. Try starting it by itself from Windows to confirm the app works normally.
  4. Run the launch again and review that item’s result in the progress window.

If the supporting app was already running, Star-Launcher may leave the existing instance in place rather than opening a duplicate.

Controller preparation failed

  1. Confirm the intended controller preset is selected for the active launch profile.
  2. Open Controller presets and verify every enabled tool is installed and correctly located.
  3. If Joystick Gremlin is enabled, confirm a valid local Gremlin profile is selected.
  4. Use Prepare controllers now to test controller preparation on its own.
  5. Read any Windows UAC prompt carefully; an enabled controller tool may require administrator approval.

The RSI Launcher was not found or the game did not start

Confirm the official RSI Launcher is installed, its path is correct, and you are signed in with required updates complete. Star-Launcher can detect visible, minimized, and tray-hidden launcher states and attempt safe recovery. If the official Update or Launch control is unavailable, follow the manual guidance shown instead of repeatedly starting new launcher instances.

Star-Launcher does not bypass login, CAPTCHA, two-factor authentication, updates, or other official requirements.

A launch stopped partway through

Review the persistent results in the progress window and acknowledge any error. Correct the failed item, then retry. Star-Launcher’s retry behavior is conservative and avoids repeating completed external actions where possible.

A profile launches when I do not expect it

Open Settings, select Preferences, and review Launch a profile after Star-Launcher opens. This setting is separate from Start Star-Launcher when Windows starts. Disable either option you do not want.

A reference, shortcut, or website will not open

  • Confirm the local file still exists and Windows has a default app for its file type.
  • Confirm web entries begin with HTTP or HTTPS.
  • For a Windows internet shortcut, confirm the .url file is valid.
  • Re-select the item in Settings if it was moved or renamed.

A captured window opens in the wrong place

Capture the position again, place and resize the template where the launched window should appear, then accept the capture. Cancelling, choosing invalid bounds, or placing the template entirely off-screen leaves the saved profile unchanged.

Profiles appear missing after an update

Make sure you are signed into the same Windows account you normally use. Close the new copy, reopen it once, and check the profile list again. Do not delete the older Star-Launcher folder until you confirm that your profiles are present.

Requesting support

Email star.launcher.support@gmail.com or join the Star-Launcher Discord. Include your Windows version, Star-Launcher version, the selected profile or preset, what you were trying to do, and the exact message shown. Never share passwords, login codes, or other private information.
