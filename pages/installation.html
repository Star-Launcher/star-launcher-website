Get started with Star-Launcher

Download, unzip, and open Star-Launcher in just a few steps.

Guides & Help

Download Star-Launcher

  1. Go to the Download section on star-launcher.com.
  2. Select Download Portable ZIP.
  3. When the download finishes, open your Downloads folder.
Use the official download.

Download Star-Launcher from star-launcher.com so you know you have the current, unmodified release.

Unzip the download

  1. Right-click the downloaded ZIP file and select Extract All.
  2. Choose a convenient location, such as a Star-Launcher folder in Documents.
  3. Open the newly extracted folder.

Star-Launcher is portable, so there is no installer. Keep the extracted files together and do not run the app from inside the ZIP.

Open Star-Launcher

  1. Double-click Star-Launcher.exe.
  2. If Windows displays a security message, confirm that the file came from star-launcher.com before continuing.
  3. Open Settings and follow the Setup guide to create your first profile.

Star-Launcher is designed for 64-bit Windows 10 and Windows 11. Most users will not need to install anything else just to open it.

Updating later

Star-Launcher can check the official stable-release feed and apply supported updates while preserving its current location and your user data. You can also update manually by closing Star-Launcher, downloading the newest ZIP, and extracting it into a new folder.
