Set up your workflow

Create a profile, choose what should start, and test the complete routine before launch day.

1. Open Settings

After extracting the Portable ZIP, run Star-Launcher.exe and select Settings. On a new computer, begin on the Setup tab.

Star-Launcher works alongside your existing game launchers.

It coordinates your preparation tools and can bring supported launchers into the workflow, but it never replaces account login, updates, or security checks.

2. Create your launch profile

  1. Select New beside the launch profile list.
  2. Give the profile a recognizable name.
  3. Use Auto-detect all application paths if desired, then verify every result. Detection can choose the wrong installation or miss one entirely.
  4. Browse to any missing application paths manually.
  5. Select Save profile settings.

You can create different profiles for different controller layouts or play styles. Profile selection and everyday profile management remain available on the main page.

3. Configure controller preparation

Controller preparation is optional. On the Controller presets tab, create or select a preset and enable only the tools you actually use, such as vJoy, HidHide, or Joystick Gremlin.

  • Confirm each enabled tool is installed and its path is correct.
  • If Joystick Gremlin is enabled, select a local Gremlin profile.
  • Save the controller preset, then choose it for your launch profile.
  • Use Prepare controllers now on the main page to test it before a full launch.

Exported presets are useful for sharing settings, but they intentionally omit machine-specific paths.

4. Choose what launches

On the main page, check only the items you want included in the current launch:

  • Supporting apps, including a configured head-tracking application.
  • Your keybind chart or shortcut.
  • Reference sheets and useful websites.
  • Your supported game launchers.

You can add personal applications, references, and websites in Settings. Web addresses must use HTTP or HTTPS, while reference files can include images, PDFs, and Windows internet shortcuts.

5. Test, then launch

  1. Select Pre-flight checks and correct any missing paths or unavailable tools.
  2. Select Launch with all selected.
  3. Follow the progress window as Star-Launcher works through each selected step.
  4. Use Stop if you need to cancel. Review and acknowledge any completion or error details before trying again.

Retries are conservative: Star-Launcher avoids repeating external actions it already completed.

Optional startup behavior

The Preferences tab can start Star-Launcher with Windows or automatically launch a profile after Star-Launcher opens. These are separate, opt-in settings. Automatic profile launch includes a visible 10-second countdown with a Cancel option.

Some selected controller tools may request Windows administrator approval. Star-Launcher does not bypass UAC prompts, launcher authentication, CAPTCHA, or two-factor authentication.
