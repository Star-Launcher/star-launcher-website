A redesigned, more flexible release of the portable Star Citizen pre-flight launcher.

Version 4.0 Stable

Released July 30, 2026

Highlights

  • Redesigned the Main and Settings screens around consistent Games, References, Supporting Apps, and Websites cards.
  • Consolidated visibility, paths, web addresses, administrator settings, and custom-entry management into the matching Setup card.
  • Added clear, labeled dialogs for creating and editing custom games, applications, references, and websites.
  • Added Star Citizen Wiki to the built-in website list.
  • Improved profile and controller-preparation controls while retaining the established launch workflow and pre-flight checks.
  • Added an optional automatic update check at startup, enabled by default for new preferences, alongside the manual update check.
  • Promoted the verified portable self-updater to the stable channel so supported installations can update in place while preserving profiles and preferences.
  • Refined the Deep-Space Indigo interface, card layout, brand presentation, action buttons, and status messaging.

Download package

Star-Launcher 4.0 Stable is distributed as Star-Launcher-4.0.0.zip, a verified portable package containing the executable, README, release manifest, and executable checksum.

Existing Star-Launcher 3.0 installations can obtain this release through the built-in updater or by replacing the release files manually. Profiles and preferences remain in place.

Version 3.0 Stable

Released July 28, 2026

Highlights

  • Completed the Star-Launcher naming and branding transition, including automatic migration of existing profiles and preferences.
  • Added versioned controller-preset import and export with validation and safe duplicate-name handling.
  • Expanded keybind references to support images, PDFs, web addresses, and Windows internet shortcuts.
  • Added movable, resizable placement templates for keybind, reference, and website windows.
  • Added a dedicated launch-progress window with Stop, persistent results, acknowledgement, and conservative safe retry.
  • Added optional automatic profile launch with a visible Cancel countdown and controller-preset override.
  • Added a consent-driven portable self-updater with stable-feed validation, download progress, checksum verification, safe replacement, and rollback.
  • Improved RSI Launcher recovery from visible, minimized, and tray-hidden states.
  • Improved recognition of a newly started Star Citizen process when RSI Launcher remains open.
  • Improved the optional vJoy preparation workflow so its configuration window opens, restores, or receives focus consistently.
  • Improved settings organization, larger text, keyboard focus, screen-reader naming, status announcements, and Windows high-contrast support.
  • Introduced the approved navigation-star identity, Deep-Space Indigo themes, and coordinated application and website branding.

Download package

Star-Launcher 3.0 Stable is distributed as Star-Launcher-3.0.0.zip, a verified portable package containing the executable, README, release manifest, and executable checksum.

A matching SHA-256 file is published with the download so the archive can be verified.

Requirements

  • Windows 10 or Windows 11, x64
  • Any optional third-party tools selected by the user

No installer, background service, or bundled third-party software is included. Existing data under %APPDATA%\Star-Launcher is preserved.

Update support

Star-Launcher 3.0 Stable includes the portable self-updater. It checks the official stable release feed and can apply supported updates while preserving the application location, profiles, and preferences. Updates require user consent and checksum verification; manual ZIP updates remain available.
