Release notes / August 15, 2026

Star-Launcher 5.1.1 Stable

Named keybind charts, clearer controller window behavior, and verified startup update defaults.

Version 5.1.1 Stable

Released August 15, 2026

  • Renamed the user-facing keybind workflow to Keybind Charts and made the primary chart name editable for aircraft-, module-, or layout-specific identification.
  • Moved Add keybind chart beside a clearly separated Additional Keybind Charts heading and clarified where extra named charts belong.
  • Added optional controller-preset actions to minimize vJoy and close HidHide after their visible setup steps complete; closing HidHide preserves its applied configuration.
  • Verified that fresh installations enable startup update checks by default while upgrades preserve the user’s existing preference.
  • Added regression coverage for fresh-install defaults and retained the full layout, updater, controller-security, migration, and deletion-safety test suites.

Version 5.1 Stable

Released August 14, 2026

  • Added one continuous nebula background image clipped across the Main-page cards while keeping the header, footer, and card gaps dark and separate.
  • Applied a stronger card overlay so text and controls remain clear without hiding the background.
  • Changed subsection labels to a higher-contrast pale periwinkle.
  • Improved checked boxes with brighter periwinkle fills and white checkmarks, and made unchecked boxes easier to see with blue-gray outlines.
  • Kept Launch Methods full width, placed Keybind Charts in the left column and Game-Specific Apps on the right, and retained that keybind-first order when the groups stack vertically.
  • Enlarged the selected game title by more than 30% and removed the redundant “Game Launch” suffix.
  • Added resize, scrolling, clipping, and responsive-column geometry tests across minimum, standard, wide, tall, and scrolled layouts.
  • Preserved existing game settings, controller presets, Utility Apps, update behavior, and 4.x/5.0 migration. Racing mode and additional controller-manufacturer presets remain deferred.

Version 5.0.2 Stable

Released August 12, 2026

  • Restricted optional controller-tool installer downloads to approved official GitHub release paths and trusted redirect hosts.
  • Added Windows Authenticode trust and expected-publisher verification before automatic vJoy or HidHide installers can run; unsupported or unverifiable releases remain manual-only.
  • Rejected unsafe imported vJoy and HidHide command text before it can reach elevated controller preparation.
  • Added deterministic security regression tests, a per-release SPDX SBOM, and a release security-test summary tied to the published hashes.
  • Added public Security & Privacy, AI-development transparency, vulnerability-reporting, and download-verification documentation.

Version 5.0.1 Stable

Released August 11, 2026

  • Moved Add launch method beside the Launch Methods section title on Main.
  • Moved Add game-specific app beside the Game-Specific Apps section title.
  • Moved Add keybind chart beside the Keybind Charts section title.
  • Removed the three separate button rows to reduce vertical space without changing saved settings, entry behavior, or launch selections.

Version 5.0.0 Stable

Released August 11, 2026

  • Replaced Main Loadout profiles with automatically saved per-game settings while keeping controller presets independent.
  • Added native tiles, Steam launching, and curated resources for Star Citizen, DCS World, Nuclear Option, Korea. IL-2 Series, Microsoft Flight Simulator, Elite Dangerous, X4: Foundations, X-Plane 12, and War Thunder.
  • Added a Main-page Reorder mode with per-tile left and right controls, user-added game tiles, and a fixed Add game tile at the end.
  • Organized each Game Launch card into Launch Methods, Game-Specific Apps, and Keybind Charts, including multiple module-specific charts.
  • Made TrackIR, Tobii, OpenTrack, GameGlass, VoiceAttack, WingmanAI, and DCS-SRS universal Utility Apps with per-game launch choices.
  • Added responsive Game Web Resources cards and configurable entries throughout Main and Settings.
  • Made Preferences universal, removed automatic profile launch at startup, and preserved existing 4.x data during migration.
  • Kept deleted native entries deleted across catalog updates and safely cleaned stale Utility App selections.
